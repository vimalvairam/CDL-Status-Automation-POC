# CDL Automation Project
## Objective
Develop a prototype to automate weekly Customer Document List status reporting.
## Planned features
- Read weekly CDL Excel files
- Track document status changes
- Identify overdue and pending documents
- Generate summary tables
- Prepare data for Power BI reporting
## Technology
- GitHub for version control
- Python for data processing
- Microsoft Excel for input data
- Power BI for dashboards
## Current stage
Learning and prototype development using synthetic sample data.
## Data protection
No confidential customer or company data should be stored in this repository.
